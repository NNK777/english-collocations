# Состояние проекта (handoff)

Файл для быстрого старта новой сессии. Читать первым.

**Обновляется по завершении этапа (юнита или раздела), а не после каждой правки.**
Последнее обновление: 21.10.2026.

## Что это

Тренажёр английских коллокаций по книге «English Collocations in Use Intermediate (2017)».
Клиентское SPA, интерфейс на русском, английские слова/коллокации — на английском.
Работает в браузере и как Telegram Mini App.

- Репозиторий: https://github.com/NNK777/english-collocations
- Прод: https://nnk777.github.io/english-collocations/
- Ветка `main`, push → GitHub Actions → GitHub Pages.
- Локально: `npm run dev -- --port 5173 --strictPort`
  → http://localhost:5173/english-collocations/
- Проверка сборки: `npm run build` (tsc + vite build)

## Стек

Vite 6 + React 19 + TypeScript + Tailwind v4. Без бэкенда.
Тема в `localStorage` (`cc-theme`): localStorage > Telegram colorScheme > системная.
`vite.config.ts`: `base: '/english-collocations/'`.

## Экраны (App.tsx)

`setup` → `intro` | `unit` (Unit 1) | `quiz` (Units 2–3) → `results`
`unit` → `presentation`
Кнопка темы в шапке. Инфо-поле показывает только выбранный раздел.

## Готово

### Введение / Introduction
- 3 сворачиваемых блока A/B/C, по умолчанию свёрнуты, аккордеон (открытие одного закрывает другие).
- Основной текст — русский, английские коллокации зелёные с подсказкой-переводом.
- Английский оригинал скрыт за кнопкой «ПОКАЗАТЬ / СКРЫТЬ АНГЛИЙСКИЙ ТЕКСТ»
  (кликабельна только надпись; текст — мелкий серый курсив).
- 3-й блок: полный текст из 5 абзацев, «English Idioms in Use» оранжевым, неверные варианты красным.

### Unit 1
Квиза нет. «Начать изучение» → подэкран с 3 кнопками (размер как у «Введение / Introduction»):
«Теория / Presentation», «Упражнения / Exercises», «Тренировка / Practice».
- **A** — готов: русский перевод как основной текст; выделенные выражения остаются
  по-английски, перевод в подсказке; английский оригинал — за тем же тогглом, что во Введении.
- **B** — готов: compounds/idioms, зелёные коллокации с переводом, «pass the buck»,
  оранжевый «English Idioms in Use»; слово `book` заменено на `course` в двух местах.
- **C** — пока заглушка, текст не добавлен.

### Units 2–3
Обычный тест: всегда 10 вопросов. Данные — 208 коллокаций в `src/data/collocations.json`
(пока распределены 69/69/70 как заглушка, реальные данные книги ещё не внесены).

## Правила оформления (не менять без запроса)

- Общий вид, фон, шрифты, цвета, переключатель темы — сохранять.
- «РАЗДЕЛ / UNIT»: широкая кнопка «Введение / Introduction» над тремя кнопками Unit 1–3.
- Заголовки вопросов: `rgb(34,80,128)` (светлая) / `rgb(96,165,250)` (тёмная).
- Зелёные коллокации: подсказка с русским переводом при наведении/тапе, шрифт подсказки 16px.
- Красные варианты — без зачёркивания.
- В русском тексте английские коллокации остаются английскими, перевод — в подсказке.

## Грабли

- Dev-сервер надо запускать вручную каждую сессию.
- GitHub Pages агрессивно кеширует; проверять с `?v=N`.
- При автоматизации браузера: клик и чтение DOM в одном `evaluate` могут гоняться
  с React — разносить по вызовам или ждать ~300–500 мс.
- `gh` CLI часто падает; статус деплоя:
  `https://api.github.com/repos/NNK777/english-collocations/actions/runs?per_page=1`

## Как поддерживать этот файл

- Обновлять «Статус этапов» и «Что дальше» **при завершении юнита/раздела**, а не после каждой правки.
- Мелкие изменения кода в файл не вносить — только смену статуса этапа.
- Коммитить вместе с завершением этапа (один коммит: код этапа + обновлённый статус).
